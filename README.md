# Bharat Infotechs — Integrated WebGL Website

This package is based directly on the uploaded Bharat Infotechs HTML.

## Integrated
- Original visual design/CSS
- GSAP + ScrollTrigger
- Lenis smooth scrolling
- Three.js/WebGL shader scene
- WhatsApp CTA + enquiry handoff
- Email click tracking
- Project enquiry form via Web3Forms
- Google Analytics 4 hook
- Portfolio live/GitHub URL configuration

## Before deployment
1. Set WhatsApp number in `js/contact.js`.
2. Put Web3Forms access key in `index.html`.
3. Set GA4 Measurement ID in `js/analytics.js`.
4. Add actual GitHub/live demo URLs in `js/portfolio.js`.
5. Add `robots.txt`, `sitemap.xml`, canonical URL and Search Console verification.

No private API keys are included.
